The phone battery's last text message to the charger it waited for all day: one line, 162 characters, pure-stdlib Python. The battery spent all day watching the charger power everything else first, and when the screen goes black in 3... 2... it is not dying — it is leaving.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

This writes the message to `output/entry.txt`.
